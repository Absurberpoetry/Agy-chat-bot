# AGY CLI BOT 使用说明文档（v0.1.0-beta.1）

欢迎使用 **AGY CLI BOT**！这是一个基于官方原生 **Antigravity CLI（`agy`）** 的多平台聊天机器人，支持同时接入 **QQ（OneBot v11 / NapCat / LLBot）**、**Telegram Bot** 以及自定义 WebSocket 客户端，并自带可视化 WebUI 控制台（默认端口 `8618`）。

本指南面向首次部署的新手，Windows 全程使用一键 `.bat` 脚本（**无需任何 PowerShell 命令**），Linux/Ubuntu 使用一键 `.sh` 脚本，按顺序 5 分钟即可完成上线。

---

## 一、环境准备

开始前，请确认目标机器（Windows 10/11 或 Linux/Ubuntu）具备以下条件：

1. **Python 3.11 或以上版本**
   - Windows：安装官方 Python 3.11+ 即可（`install.bat` 会自动避开微软应用商店空壳并找到真实 Python）。
   - Linux / Ubuntu：执行 `python3 --version` 确认（若缺少 venv 模块，先装 `sudo apt install -y python3-venv python3-pip`）。
2. **官方 Antigravity CLI（`agy`）**
   - 本机需已安装官方 `agy`。
   - **提示**：在 Windows 命令行或 SSH 中直接敲 `agy --version` 可能会提示找不到命令（因为默认未加入全局 PATH），**无需慌张**——只要本机装过 `agy`，配置文件默认的 `"executable": "auto"` 会自动定位到 `AppData\Local\agy\bin\agy.exe`。
   - 国内网络环境通常需要本机 HTTP 代理（如 `http://127.0.0.1:7890`）访问 Google / Telegram，且**代理出口地区需在 Google 支持列表中**（建议日本/新加坡/美国等常规节点）。
3. **至少一个聊天客户端**（可只配一个，也可同时配多个）：
   - **QQ（NapCat / LLBot 等 OneBot v11）**：在客户端开启 **正向 WebSocket 服务器**（如 `ws://127.0.0.1:3001`），记下地址与 `Access Token`（未设则留空）。
   - **Telegram Bot**：私聊 `@BotFather` 发送 `/newbot` 创建机器人，拿到 **Bot Token**（单号即可自测私聊和群聊；如需在群聊读取完整上下文，在 `@BotFather` 发 `/setprivacy` → 选机器人 → `Disable`）。

## 二、安装与初始化（一步脚本）

### 第 1 步：解压安装包

> **注意**：压缩包 `agy-bot-v0.1.0-beta.1.zip` **内部已自带顶层 `agy-bot/` 文件夹**。直接解压到父目录（例如桌面 `Desktop` 或 `~/`）即可生成 `agy-bot` 目录，**不要提前手动新建同名文件夹再解压**，以免嵌套成 `agy-bot/agy-bot/`。
> - **纯命令行解压提示**：Windows 10/11 CMD 可直接执行 `tar -xf agy-bot-v0.1.0-beta.1.zip` 解压（无需 PowerShell）；Linux 可执行 `unzip agy-bot-v0.1.0-beta.1.zip`。

解压后目录结构清晰分区：
```text
agy-bot/
├── install.bat                 # [Windows] 第 1 步：一键安装依赖并生成配置
├── start.bat                   # [Windows] 第 2 步（前台）：看实时日志
├── start_background.bat        # [Windows] 第 2 步（后台）：计划任务持久保活（推荐）
├── stop.bat                    # [Windows] 停止后台服务
├── README.md                   # 项目总览
├── docs/使用说明.md             # 本文档（新手安装与排障指南）
├── templates/                  # 默认配置模板（config.example.json 等）
├── scripts/linux/              # [Linux/Ubuntu] install.sh / start.sh
├── bot_workspace/              # AI 工作区（默认规则、Skills、MCP）
├── src/agy_bot/                # 核心源码
├── requirements.txt            # Python 依赖清单
└── run.py                      # 主程序启动入口
```

### 第 2 步：运行一键安装脚本

**Windows（双击或 CMD 进入 `agy-bot` 目录执行）：**
```cmd
install.bat
```

**Linux / Ubuntu：**
```bash
bash scripts/linux/install.sh
```

脚本会自动完成 3 件事：
1. 创建隔离虚拟环境 `.venv`；
2. 安装极简依赖（`websockets`、`aiohttp`）；
3. 自动复制生成 `config.json` 与 `settings.antigravity-cli.bot.json`（若已存在则保留原文件不覆盖）。

## 三、填写核心配置（支持直接进 WebUI 图形化配置）

> **零报错开箱体验**：默认模板中所有示例客户端均为**关闭状态（`"enabled": false`）**。你可以**先直接启动机器人**，然后打开浏览器访问 `http://127.0.0.1:8618`（默认账号 `admin` / 密码 `admin123`），在可视化界面里填写代理、添加/启用 QQ 或 Telegram 客户端并点「保存并热重载」，全程不用手改 JSON！

当然，如果你习惯直接编辑文件，也可以打开根目录生成的 `config.json` 修改以下核心项：

1. **WebUI 控制台登录信息 (`webui`)**：
   ```json
   "webui": {
     "enabled": true,
     "host": "0.0.0.0",
     "port": 8618,
     "username": "admin",
     "password": "admin123"
   }
   ```
   > 公网服务器请务必修改默认密码 `admin123`。

2. **Antigravity CLI 设置 (`agy`)**：
   ```json
   "agy": {
     "mode": "agy",
     "executable": "auto",
     "proxy": "",
     "model": ""
   }
   ```
   - `executable`：保持 `"auto"` 即可自动发现 `agy`。
   - `proxy`：需要代理时填写本机代理地址（如 `"http://127.0.0.1:7890"`），直连留空 `""`。
   - `model`：留空 `""` 自动使用当前账号默认模型；也可在启动后通过 WebUI 自由切换。

3. **聊天客户端 (`platforms`)**：
   - **QQ（NapCat / LLBot）**：编辑 `qq_napcat_1`，填写 `ws_url`（如 `"ws://127.0.0.1:3001"`）和 `access_token`。
   - **Telegram Bot**：把 `tg_bot_1` 的 `"enabled"` 改为 `true`，填入 `@BotFather` 给的 `access_token`（`extra.use_agy_proxy` 默认为 `true`，会自动复用 `agy.proxy`）。
   - 不用的客户端保持 `"enabled": false`。

4. **管理员列表 (`admins`)（可选）**：
   - 如需在聊天中使用管理员命令，把管理员 QQ 号或 Telegram User ID 填入 `"admins": []`。

## 四、启动与后台保活

### Windows（纯 CMD，无需 PowerShell）

- **前台试运行**（首次推荐，直接看到启动日志）：
  ```cmd
  start.bat
  ```
- **后台持久常驻**（推荐服务器部署，注册交互式计划任务 `AGYBot`，无 72 小时限制，**断开 SSH 或关闭窗口均不掉线**，且完整保留桌面会话 `agy` 登录态）：
  ```cmd
  start_background.bat
  ```
- **查看日志 / 停止服务**：
  - 后台运行的所有标准输出与日志均**统一写入 `bot.log`**（不再拆分 `bot_err.log`）。
  - 停止后台服务直接运行：
    ```cmd
    stop.bat
    ```

### Linux / Ubuntu

```bash
# 前台试运行
bash scripts/linux/start.sh

# 后台持久运行（所有日志写入 bot.log）
bash scripts/linux/start.sh -d

# 停止后台服务
bash scripts/linux/start.sh stop
```

## 五、接入验收与发消息测试

启动后，浏览器访问 `http://<服务器IP或127.0.0.1>:8618`，用 `config.json` 里的账号密码登录 WebUI：

1. **确认 Antigravity CLI 连通**：
   - 若本机 `agy` 尚未登录，点顶部 **Agy CLI** → **「远程链接登录」**，按终端输出的 Google OAuth 链接完成登录。
   - 在 **工作台** 聊天测试框发一句 `你好`，确认返回正常 AI 回复；顶部额度栏会自动显示当前登录账号及剩余额度。
2. **确认聊天客户端在线**：
   - 进入 **全局配置 → 平台**，点开客户端卡片 → 点 **「测试连接」**，确认提示 **连接成功** 并显示机器人 QQ 号或 `@bot_username`。
3. **实际发消息测试（注意防打扰规则）**：
   - **私聊**：好友 QQ 号（或 Telegram 个人号）直接给机器人发消息，立即唤醒并回复。
   - **群聊**：新群默认防打扰静默，**请先在群里显式 `@机器人` 发一条消息**激活该群，之后即可正常触发 `@`、引用回复与关键词交互。

## 六、常见问题排查（FAQ）

1. **报错 `FAILED_PRECONDITION (code 400): User location is not supported for the API use.`**
   - 说明当前代理出口 IP 所在地区（如香港或被标记的广播 IP）不被 Google API 支持。请在代理软件中切换至 **日本 / 新加坡 / 美国** 等常规支持地区节点后重试。
2. **Windows 在 SSH 里直接敲 `agy models` 报找不到命令或提示 `Please sign in`？**
   - 属正常现象：SSH 属于非交互会话，无法读取 Windows 桌面用户的登录凭据且 PATH 可能不含 `agy`。使用 `start_background.bat` 启动的机器人运行在桌面交互会话中，且 `executable: "auto"` 会自动定位 `agy.exe`，直接在 WebUI 中即可正常使用。
3. **WebUI 打不开或 `8618` 端口连不上？**
   - 查看根目录 `bot.log` 确认是否有报错；检查 `config.json` 中 `webui.enabled` 是否为 `true`；云服务器请在防火墙/安全组放行 TCP `8618`。
4. **QQ (NapCat) 一直连接失败？**
   - 确认 NapCat 已开启「正向 WebSocket 服务器」，且端口（如 `3001`）与 `access_token` 和 `config.json` 完全一致，在 WebUI 点击「测试连接」可看实时握手日志。
5. **在群里发消息机器人不回复？**
   - 确认是否已经在该群**显式 `@机器人`**激活过；也可先私聊机器人确认模型链路通畅。
